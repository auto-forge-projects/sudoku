# DL-04-004: Kod paketleme = klasik script + çift dışa-aktarım (ESM değil)

- Tarih: 2026-07-25
- Faz: 4 — Çözüm Analizi
- Mod: AUTOPILOT
- Karar: Çekirdek mantık klasik `<script>` ile yüklenir ve iki ortama birlikte açılır: `window.SudokuCore = {...}` + `typeof module !== 'undefined' && (module.exports = ...)`. Böylece aynı dosya tarayıcıda `file://` ile, HTTP üzerinde ve Node test koşucusunda (`require`) çalışır. Derleme/bundler/paket bağımlılığı yok.
- Değerlendirilen alternatifler: (A) ES modules (`<script type="module">` + `export`).
- Gerekçe: A, `file://` açılışta CORS nedeniyle modül yükleyemez; bu, "index.html'e çift tıkla oyna" senaryosunu ve NFR-3'ün ruhunu (ek araç gerektirmeden çalışma) bozar. B'nin maliyeti 3 satırlık guard; kazanç hem çift tıkla açılış hem bağımlılıksız `node --test` importu.
- Riskler: Global namespace kirliliği ve modern modül ergonomisinden feragat → tek global (`SudokuCore`) ile sınırlanır; dosya büyürse (>~600 satır) ESM + basit HTTP servis yeniden değerlendirilir.
- Geri alınabilirlik: Yüksek — ESM'e geçiş dosya başı/sonundaki dışa-aktarım satırlarını ve `<script>` etiketini değiştirmekten ibaret.
- İnsan onayı: Otomatik
