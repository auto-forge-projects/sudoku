# DL-06-001: Tek ekran, ARIA grid tabanlı UI sözleşmesi

- Tarih: 2026-07-25
- Faz: 6 — UI/UX
- Mod: AUTOPILOT
- Karar: Sudoku tek ekranlı bir web arayüzü olarak tasarlandı: 81 hücrelik statik `role="grid"` yapısı, roving-tabindex klavye gezinmesi, `aria-live` durum satırı ve tek "Yeni Oyun" butonu. Ek ekran/mod (zorluk seçimi, çoklu sayfa) yok.
- Değerlendirilen alternatifler: (a) `<input>` tabanlı hücreler — tarayıcı odak/validasyon davranışı mimari D3 (statik element + class diff) ile çakışıyor; (b) çoklu zorluk ekranı — FR kapsamı dışı (Faz 3'te "tek zorluk seviyesi" varsayımı).
- Gerekçe: Mimaride (Faz 5) zaten sabitlenen statik 81-element + class-diff render sözleşmesiyle birebir uyumlu; `role="grid"`/`gridcell` + roving tabindex NFR-4'ü (klavye erişilebilirliği) native `<input>` karmaşası olmadan karşılar.
- Riskler: Ekran okuyucu uyumluluğu manuel test edilmedi (yalnız ARIA örüntüsü uygulanıyor) — Faz 11'de kenar durum olarak not edilebilir.
- Geri alınabilirlik: Yüksek (yalnız `index.html`/CSS/render sözleşmesi; `core.js` mantığı etkilenmez).
- İnsan onayı: Otomatik
- Varsayım mı?: Evet — AUTOPILOT varsayımı: dokunmatik/mobil jest desteği v1 kapsamı dışı bırakıldı (NFR-3 yalnız masaüstü tarayıcıları hedefliyor).
