# DL-05-004: Klavye erişilebilirliği mimarisi — roving tabindex + model-tabanlı selected + aria-live

- Tarih: 2026-07-25
- Faz: 5 — Mimari Tasarım
- Mod: AUTOPILOT
- Karar: `selected` DOM'dan değil `Board` modelinden okunur/yazılır. Grid `role="grid"`, hücreler roving `tabindex` (seçili hücre `tabindex=0`, diğerleri `-1`). Ok tuşları index aritmetiğiyle (`±1` sütun, `±9` satır, kenarda kırpma) `selected`'ı günceller. `givens` hücreleri `aria-readonly="true"`, çakışan hücreler `aria-invalid="true"`; `#status` `aria-live="polite"` ile tamamlanma duyurusu yapılır (FR-4).
- Değerlendirilen alternatifler: (A) 81 adet native `<input>` elemanı (tarayıcı odak/klavye davranışını ücretsiz alır).
- Gerekçe: Native `<input>` yaklaşımı `maxlength`/sayısal kısıt/stil tutarlılığı için ekstra iş ister ve grid navigasyonunu (ok tuşlarıyla hücreler arası atlama) native olarak desteklemez; model-tabanlı `selected` + roving tabindex NFR-4'ü daha az yüzey alanıyla karşılar ve render sözleşmesiyle (DL-05-003) tutarlıdır — render odak kimliğini korur.
- Riskler: Roving tabindex yanlış uygulanırsa Tab tuşuyla gridin dışına çıkışta tuzak (focus trap) oluşabilir → Faz 11'de klavye-only gezinme senaryosu test edilir.
- Geri alınabilirlik: Orta — ARIA sözleşmesi HTML şablonuna gömülü; değişiklik hem `index.html` hem `app.js` hem `render.js`'i etkiler.
- İnsan onayı: Otomatik
